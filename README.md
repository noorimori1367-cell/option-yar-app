# آپشن‌یار — نسخه ۱.۲.۰ (بهبود محتوا و تجربه یادگیری)

اپلیکیشن موبایل فارسی (React Native / Expo) برای آموزش جامع بازار اختیار معامله؛ از مفاهیم کاملاً مبتدی تا استراتژی‌های ترکیبی پیشرفته، با تمرکز ویژه بر سازوکار اجرایی بازار ایران.

## تغییرات این نسخه (۱.۲.۰)

نسخه قبلی (۱.۱.۰) از نظر پوشش موضوعی کامل بود، اما بخش زیادی از فیلدهای «نکته عملی»، «اشتباه رایج» و «ریسک» در ۴۰ درس، متن یکسان و تکرارشونده داشتند. این نسخه این بخش‌ها را به‌طور کامل بازنویسی کرده است:

- **محتوای اختصاصی برای هر ۴۰ درس**: فیلدهای «منطق و مکانیزم»، «نکته عملی معامله‌گر»، «دام رایج» و «ریسک‌ها» دیگر متن مشترک ندارند؛ هرکدام مخصوص همان درس بازنویسی شده‌اند.
- **جدول سناریوهای سود و زیان**: برای هر ۲۳ درس استراتژی (فصل چهارم و پنجم) یک جدول عددی با ۴ تا ۵ سناریوی قیمتی، به‌همراه Break-even، حداکثر سود و حداکثر زیان به‌صورت فیلدهای مجزا اضافه شده و در اپ به‌صورت کارت‌های رنگی (سبز=سود، قرمز=زیان) نمایش داده می‌شود.
- **بخش «اثر گذر زمان و تغییر IV»**: به‌عنوان بخش مستقل در هر درس استراتژی اضافه شد.
- **تکمیل دو درس ناقص فصل پنجم**: «فروش حفاظتی» (Married Put / Protective Put) و «خرید امانی» (Fiduciary Call) که در نسخه قبلی به‌صورت پیش‌نویس/جای‌گیرنده رها شده بودند، بر اساس تعریف استاندارد OIC/Cboe (اصل برابری Put-Call) کامل بازنویسی شدند و درس مقایسه آن‌ها (فصل ۱۳ همین بخش) نیز به‌روزرسانی شد.
- **ارجاع به منابع Cboe Options Institute و Options Industry Council (OIC)** در کنار منابع قبلی بامبو فاند، مطابق درخواست اولیه پروژه.
- **گسترش آزمون پایان فصل**: تعداد سؤالات هر فصل متناسب با تعداد درس‌هایش افزایش یافت (فصل پنجم از ۳ به ۱۲ سؤال).
- **ذخیره پاسخ‌های تمرین**: پاسخ سؤال فوری هر درس و آزمون پایان فصل، مثل تیک پیشرفت، در حافظه دستگاه ذخیره و بعد از بستن اپ حفظ می‌شود.

ساختار فصل‌ها و اسکریپت Build نسبت به نسخه قبلی حفظ شده است.

## پوشش موضوعی

مقدمه و مفاهیم پایه (Call/Put، ITM/ATM/OTM، پریمیوم) ← ارزش‌گذاری (ارزش ذاتی/زمانی، Greeks، نوسان ضمنی، بلک–شولز، وجه تضمین) ← تابلوخوانی و اجرا (سامانه معاملاتی، اقدامات شرکتی، اعمال و تسویه) ← استراتژی‌های پایه (چهار موقعیت پایه و Payoff) ← استراتژی‌های ترکیبی (Covered Call، Straddle، Strangle، Bull/Bear Call/Put Spread، Married Put/Fiduciary Call، Collar، معاملات اهرمی).

## نکته فونت

فایل فونت Sahel داخل این مخزن توزیع نشده است. GitHub Actions هنگام Build آن را مستقیماً از مخزن رسمی Sahel دریافت می‌کند و سپس APK را می‌سازد.

## جایگزینی در GitHub

تمام فایل‌های این پروژه (به‌خصوص `App.js` و `src/course.js`) را روی فایل‌های قبلی Repository خودت Upload/Replace کن. پوشه `scripts/` فقط برای ساخت این نسخه از محتوا استفاده شده و بخشی از اپ نیست؛ نگه‌داشتنش در مخزن اختیاری است (برای ادغام آسان‌تر نسخه‌های بعدی مفید است).
