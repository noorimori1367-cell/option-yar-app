# آپشن‌یار V5 — آپدیت محتوای بازار آپشن ایران

این همان پروژه قبلی آپشن‌یار است و ساختار اصلی فصل‌ها حفظ شده است.

## تغییرات این آپدیت
- ادغام محتوای آموزشی بخش اختیار معامله بامبو در درس‌های موجود
- توسعه Call و Put با مثال و نکات عملی
- توسعه تسویه نقدی و فیزیکی، اندازه قرارداد، وجه/دارایی لازم و چک‌لیست سررسید
- توسعه تابلوخوانی، نمادها، کارگزاری و ابزارهای تحلیلی
- آزمایشگاه داخلی Black–Scholes و Greeks
- تکمیل Payoff و استراتژی‌های Covered Call، Short Put و Call Spread
- سؤال فوری متفاوت و متناسب برای هر یک از ۴۰ درس
- حفظ پیشرفت و تیک یادگیری
- بهبود کامل RTL و writingDirection برای جلوگیری از به‌هم‌ریختگی حروف فارسی
- استفاده از فونت Sahel در APK

## نکته فونت
فایل فونت داخل این ZIP توزیع نشده است. GitHub Actions هنگام Build آن را مستقیماً از مخزن رسمی Sahel دریافت می‌کند و سپس APK را می‌سازد.

## جایگزینی در GitHub
تمام فایل‌های این ZIP را روی فایل‌های قبلی Repository خودت Upload/Replace کن.

## Build APK
Secret به نام `EXPO_TOKEN` باید از قبل وجود داشته باشد.
سپس:
Actions → Build Android APK → Run workflow
